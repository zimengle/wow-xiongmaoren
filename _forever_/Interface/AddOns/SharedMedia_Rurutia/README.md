# SharedMedia_Rurutia

版本：2.2.6

本包供正式服（Interface 120100）和《魔兽世界：无限》（Interface 16001）共用，向 LibSharedMedia 注册露露的语音、音效、字体和材质。

将 SharedMedia_Rurutia 文件夹放入对应客户端的 Interface/AddOns。首次安装后重启游戏；更新后可 /reload，在支持 LibSharedMedia 的插件中选择资源。

其他怀旧客户端使用独立的 Classic 版本。
