# BugSack 无限服独立维护版

版本：v12.1.1-fix

仅支持魔兽世界：无限 1.60.1（Interface 16001）。

需要同时安装 !BugGrabber。本版不包含报错音频，不注册或播放任何报错音，也不提供音效选择、试听或取消静音选项。旧版音效设置在加载时清理。

设置保存修补已通过本地模拟验证，实际客户端仍需重载后确认。

安装时将 BugSack 文件夹放入 _classic_beta_/Interface/AddOns。插件目录名和数据库名沿用原版，请勿与原版同时安装。
