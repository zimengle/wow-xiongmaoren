# RurutiaSuite

**Version:** 4.7.4

露露的多客户端魔兽世界工具箱。一个插件包同时覆盖 Retail 与 TOC 中列出的 Classic 客户端，并按客户端能力装配对应模块。

## 使用

- 输入 `/rs` 打开主界面。
- 输入 `/rsm` 进入移动模式。
- 可选安装 `RurutiaSuite_Setup`，用于安装和维护露露的 Retail 配置预设。

## 主要功能

- 聊天条、顶部快捷工具、快速焦点与团队标记。
- CVar、小工具、玩家提示和战斗提醒。
- Retail骑士附魔、道标与全职业大餐提醒，和焦点提醒共用中央文字位置。
- 无限法师奥术智慧、霜甲术缺失时显示中央文字，仅脱战检测，默认休息时不提醒。
- Classic 消耗品动作条、法师传送条、经验条与客户端专属兼容。

旧版配置会按已登记的命名空间迁移；无法确认的未知字段会保留，不会静默清理。
