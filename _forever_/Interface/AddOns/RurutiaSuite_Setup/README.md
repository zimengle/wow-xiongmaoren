# RurutiaSuite Setup

**Version:** 4.6.9

露露配置安装器，需要与同版本的 `RurutiaSuite` 一起使用，支持正式服与无限。

无限目前仅安装 `data/编辑模式代码_无限_16比9.txt` 提供的16:9编辑模式。一键安装与分项导入使用同一份预设，默认开启登录、重载及切专精使用已安装的“露露”布局。默认左布局，保留左右布局按钮，切换暂不可用，等待后续适配。

## 使用

- 从 RS 设置页进入配置安装器。
- 也可从 ESC 菜单的“露露的工具箱”进入。
- 支持一键全部或分项安装；写入前会检查目标插件、当前状态和可恢复条件。
- 一键安装或单独导入编辑模式完成后直接重载界面；一键安装等待全部分项结束，若期间进入战斗则脱战后重载。

安装器不会替代玩家的游戏内确认。第三方插件提示重新载入界面时，请按提示 `/reload` 后检查结果。

## Elles布局贴边

先在EUI中准备“露露-左布局”“露露-中布局”“露露-右布局”。在安装器的“安装布局”页切换，默认自动贴边；也可点击“边缘修正”直接调整，无需额外确认。修改分辨率或UI缩放后可再次使用。

主动作条、左右下信息条、小地图及右侧动作条贴边，已有锚点带动关联元素；队列状态位于小地图内部右下，经验条贴齐小地图底边和屏幕右边，声望条与经验条重叠，背包贴齐屏幕右下角。聊天框保留信息条上方间距，左布局团框放到左上角；中布局保留底部并排和两行动作条上下排列。字号与尺寸保持不变，可在本次会话内“撤销贴边”；手动改过布局、切换配置或改变画布后，需要重新操作。

战斗、EUI布局编辑、独立专精/条件位置层、必要组件未就绪或空间不足时停止并提示。原有隐藏设置不变。自动功能和登录检查分别位于“自动设置”“检查预设”；从异常提醒进入时直接打开检查详情。设计档由现有配置供给流程提供，贴边按钮不创建配置档。
