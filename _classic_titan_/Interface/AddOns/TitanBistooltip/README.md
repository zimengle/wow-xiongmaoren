TitanBistooltip 是一款适用于《魔兽世界》泰坦重铸时光服的插件，主要用于显示职业和专精的最优装备(BIS)排名、附魔、宝石建议、以及增强鼠标BIS提示的功能。

对于新手玩家，TitanBistooltip能帮助快速了解装备优先级，避免被某些人误导。

TitanBistooltip支持三种语言：中文简体、繁体以及英文。

快跑兄弟持续在完善各个阶段！

主要功能:
1. BIS装备面板：显示各职业各专精在不同阶段的推荐装备、附魔、宝石等。
2. 毕业装备面板：显示各职业各专精的在不同阶段的毕业装备
3. 装备收集进度：跟踪玩家收集毕业装备的进度
4. 装备排名系统：在查看装备或者鼠标悬停装备上时显示其在BIS列表中的排名
5. 物品复制功能：支持右键点击装备、宝石、附魔名称复制到剪贴板

数据库：快跑兄弟的本地数据库。
当前的数据统计：
- 总职业数：10个，包含死亡骑士、圣骑士、德鲁伊、猎人、牧师、法师、战士、潜行者、术士、萨满。
- 总专精数：32个（2026.1.27新增-盗贼敏锐专精；2026.3.18新增-死亡骑士鲜血输出专精）
- 总装备数据：约1600件
- 支持阶段：PR、P1、P2、P3

打开BIS装备面板：
- 使用命令/bis、/titanbistooltip 打开 BIS面板
- 或点击小地图T图标打开面板

面板选项：
- 过滤专精：可以选择只显示特定专精的BIS排名
- 过滤职业：可以选择特定职业的BIS装备提示
- 过滤阶段：可以选择特定阶段的鼠标BIS提示
- 工具提示位置：设置装备排名信息在工具的方位
- 高亮天赋：可以高亮显示特定天赋的装备排名

已知问题：
