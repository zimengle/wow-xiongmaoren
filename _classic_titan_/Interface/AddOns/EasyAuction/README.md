# EasyAuction 拍卖行插件使用指南

## 插件简介

EasyAuction 是一款功能强大的魔兽世界拍卖行增强插件，专为简化拍卖操作、提供价格参考和辅助商业决策而设计。插件支持自动采集拍卖价格、快速上架物品、价格趋势分析、商机发现等功能，帮助玩家更高效地管理拍卖活动。

## 主要功能

### 1. 自动采集拍卖价格

插件会自动记录拍卖行中的物品价格信息，包括：
- 市场在售最低价
- 历史价格走势
- 每日价格波动
- 物品上架数量统计

### 2. 快速上架与价格参考

- **一键填入价格**：拖动物品到上架栏，自动弹出历史价格，点击即可填入
- **自动压价**：支持按配置的金额自动压价，提高物品竞争力
- **跟价功能**：快速匹配当前市场价格
- **一键上架**：简化拍卖流程，提高操作效率

### 3. 价格数据库与走势分析

- **价格库浏览**：查看所有采集过的物品价格信息
- **日K线走势图**：直观展示物品价格变化趋势
- **历史最低价**：记录并显示物品历史最低价格
- **分类浏览**：按物品类别组织价格数据

### 4. 商机发现

- **智能筛选**：快速找出低于市场价的物品
- **套利空间分析**：计算潜在利润空间
- **价值评估**：基于分解、选矿、研磨等收益进行综合评估

### 5. 常用与最近记录

- **最近搜索**：自动记录最近搜索的物品
- **常用物品**：手动添加或从最近搜索中收藏常用物品
- **快速访问**：一键查询常用物品的价格信息

### 6. 交易记录

- **购买记录**：记录所有通过插件购买的物品
- **拍卖记录**：跟踪已发布的拍卖物品
- **交易统计**：汇总交易数据，便于财务分析

### 7. 闪购模式

- **快速购买**：点击拍卖记录直接购买，无需确认
- **安全保障**：大额交易仍会弹出系统确认窗口

## 界面介绍

### 1. 主界面标签页

- **搜索**：搜索物品并采集价格信息
- **拍卖**：物品上架与价格设置
- **价格库**：浏览历史价格与趋势分析
- **常用**：快速访问常用物品
- **最近**：查看最近搜索的物品

### 2. 价格库界面

- **物品列表**：显示所有采集过的物品
- **排序功能**：按名称、价格、时间等排序
- **筛选功能**：快速查找特定物品
- **走势按钮**：查看物品价格走势图
- **寻找商机**：筛选潜在利润物品

### 3. 配置界面

- **基本设置**：拍卖持续时间、堆叠数量等
- **价格显示**：鼠标提示中的价格信息设置
- **功能开关**：启用/禁用特定功能
- **界面设置**：调整插件界面大小和位置

## 使用方法

### 1. 初始化与价格采集

1. **进入拍卖行**后，切换到**搜索**标签页
2. **搜索**你关心的物品，或使用**全局扫描**进行批量价格采集
3. 插件会自动记录价格信息，为后续操作提供参考

### 2. 物品上架流程

1. 切换到**拍卖**标签页
2. **拖动物品**到上架栏
3. 插件会自动弹出**历史价格**窗口
4. **点击价格**一键填入，或手动调整
5. 设置**堆叠数量**和**拍卖持续时间**
6. 点击**开始拍卖**完成上架

### 3. 价格分析与商机发现

1. 切换到**价格库**标签页
2. **浏览**或**搜索**特定物品
3. 点击**走势**按钮查看价格变化趋势
4. 点击**寻找商机**按钮筛选潜在利润物品
5. 基于价格信息做出购买或出售决策

### 4. 常用功能使用

- **添加常用物品**：在最近搜索中右键点击物品，选择"添加到常用"
- **管理常用物品**：在常用标签页中管理常用物品列表
- **快速查询**：在常用或最近标签页中点击物品，快速查看价格信息

## 配置选项

### 基本设置

- 起拍价折扣比例（默认0.99）
- 自动压价金额（默认1铜）
- 默认堆叠数量（默认20）
- 默认拍卖持续时间（默认12小时）

### 价格显示设置

- 启用EasyAuction鼠标提示
- 显示拍卖价格信息
- 显示卖店价
- 显示历史最低价格
- 显示分解价值
- 显示选矿价值
- 显示研磨价值
- 总价/单价显示优先

### 功能设置

- 启用自动压价
- 连续上架相同物品自动同价
- 隐藏原生卖店价

### 界面设置

- 界面缩放比例（默认1.0）
- 锁定界面位置
- 控制各功能区块显示

## 常用命令

- **/epah**：打开价格数据库界面
- **/epsp**：开关物品鼠标提示中的价格与分解信息

## 小技巧

1. **快速搜索**：在背包中Shift+左键点击物品，自动填入搜索框
2. **库存操作**：在待售库存列表中，左键复制价格，右键快速上架或移除常用
3. **宏命令**：使用`/click EasyAuctionStartBtn`宏调用开始拍卖按钮
4. **价格对比**：按住Shift键切换总价/单价显示
5. **批量操作**：使用全局扫描一次性采集多个物品价格

## 注意事项

1. **价格参考**：插件提供的价格仅供参考，实际定价请结合市场情况
2. **数据准确性**：首次使用时需要先搜索或扫描物品，才能获得准确价格
3. **拍卖刷新**：拍卖行长时间未刷新时，建议点击"刷新"按钮获取新价格
4. **插件冲突**：如遇界面卡顿或功能异常，可使用"极简模式"排查冲突
5. **闪购模式**：开启后请谨慎操作，防止误买高价物品

## 常见问题

### Q: 为什么物品没有价格信息？
A: 插件需要先采集物品价格，首次使用时请先搜索该物品或使用全局扫描。

### Q: 价格数据多久更新一次？
A: 价格数据在每次搜索或扫描时更新，建议定期更新以保持数据准确性。

### Q: 如何清除历史价格数据？
A: 在价格库界面点击"重置"按钮，可清空所有拍卖历史记录和设置。

### Q: 插件支持多账号或多服务器吗？
A: 插件数据按服务器和阵营分开存储，支持多账号使用，但各账号数据独立。

### Q: 如何备份插件数据？
A: 插件数据存储在`WTF/Account/账号名/SavedVariables/EasyAuction.lua`文件中，定期备份该文件即可。

## 故障排除

### 1. 界面不显示
- 检查插件是否已启用
- 尝试使用`/epah`命令打开价格库
- 检查是否与其他插件冲突

### 2. 价格数据不准确
- 确保已进行价格采集
- 检查拍卖是否已刷新
- 尝试重新扫描物品价格

### 3. 功能无响应
- 检查游戏客户端是否为最新版本
- 尝试禁用其他可能冲突的插件
- 重置插件设置并重新配置

### 4. 数据丢失
- 定期备份SavedVariables文件
- 避免在游戏运行时修改插件文件
- 如遇数据损坏，可尝试使用备份恢复
